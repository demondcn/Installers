UdeC Asistencia - Sonido de verificacion v2

Esta version reproduce un archivo WAV real cuando detecta un ingreso exitoso.

SONIDO ACTUAL
- sounds/success.wav
- En esta copia corresponde al archivo GLaDOS-834585.wav suministrado.

PARA CAMBIAR EL SONIDO
1. Consiga cualquier archivo WAV compatible.
2. Renombrelo exactamente a: success.wav
3. Reemplace el archivo dentro de la carpeta: sounds
4. Abra chrome://extensions o edge://extensions
5. Pulse "Recargar" en la extension.

No se recomienda apuntar a una ruta como:
file:///C:/Users/demondcn/Downloads/GLaDOS-834585.wav
porque una pagina HTTPS y una extension pueden tener restricciones de acceso a archivos file://,
y ademas esa ruta deja de funcionar en otros PCs o con otro nombre de usuario.

INSTALACION
1. Descomprima esta carpeta.
2. Abra chrome://extensions o edge://extensions
3. Active Modo desarrollador.
4. Cargar descomprimida.
5. Seleccione esta carpeta.

La extension solo actua en las paginas de asistencia de la UdeC configuradas en manifest.json.
