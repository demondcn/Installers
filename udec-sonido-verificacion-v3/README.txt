UdeC Asistencia - Sonido de verificacion v3

SONIDO ACTUAL
- sounds/success.mp3
- Correcaminos - Bip Bip (archivo suministrado).

FUNCIONAMIENTO
- El sonido NO se reproduce simplemente al pulsar INGRESAR.
- Se arma al pulsar INGRESAR o enviar Enter desde el campo.
- Solo suena cuando la pagina muestra una ficha que contiene DOCUMENTO, ROL y MODALIDAD.

PARA CAMBIAR EL SONIDO
1. Use un archivo MP3.
2. Renombrelo exactamente a: success.mp3
3. Reemplace el archivo dentro de la carpeta sounds.
4. Abra chrome://extensions o edge://extensions.
5. Pulse Recargar en la extension.

INSTALACION
1. Descomprima la carpeta.
2. Abra chrome://extensions o edge://extensions.
3. Active Modo desarrollador.
4. Pulse Cargar descomprimida.
5. Seleccione la carpeta udec-sonido-verificacion-v3.

La extension solo actua en las paginas de asistencia UdeC configuradas en manifest.json.
