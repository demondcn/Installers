UdeC Asistencia - Sonido de verificación
=========================================

Qué hace
--------
Cuando se pulsa INGRESAR (o se envía el código con Enter) en la página de asistencia,
el complemento queda atento durante 20 segundos. Si aparece la ficha exitosa con los
campos DOCUMENTO, ROL y MODALIDAD, reproduce un sonido corto de confirmación.

No modifica ni envía datos adicionales a la plataforma.

Instalación en Chrome / Edge / Opera
------------------------------------
1. Descomprimir la carpeta.
2. Abrir la página de extensiones del navegador.
3. Activar "Modo desarrollador".
4. Pulsar "Cargar descomprimida" / "Load unpacked".
5. Seleccionar la carpeta "udec-sonido-verificacion".
6. Abrir nuevamente la página de asistencia y probar un ingreso válido.

Nota
----
El navegador debe tener sonido habilitado para plataforma.ucundinamarca.edu.co.
Si el sitio está silenciado desde la pestaña o Windows, no se oirá la confirmación.
